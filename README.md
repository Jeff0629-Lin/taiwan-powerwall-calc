# 台灣住宅電費試算

手機 / 桌面皆可用的台灣住宅電費試算工具，比較三種方案的每月電費並估算 Powerwall 儲能回本年限。

## 功能

- **三方案比較**：累積電價 vs. 簡易型時間電價（二段式）vs. 時間電價＋儲能
- **對帳單反推**：時間＋儲能尖峰比例拉到與台電帳單相符，再依電池容量 × 放電天數加回移轉量，還原「只申請時間電價」的費用與尖峰比例
- **回本年限試算**：輸入 Powerwall 安裝費用，自動分季加權估算回本年數
- **即時互動**：拉桿調整用電量、時間＋儲能尖峰比例、電池容量、放電天數、夏季／非夏季
- **離線可用**：純 HTML/CSS/JS，無外部相依，存到手機即可使用

## 計算方式

- 每月總用電量：填台電 App 顯示的當月度數
- 累積電價：依級距逐段累加，**無基本費**
- 時間＋儲能：`電費 = 75 + 度數 × 尖峰比例 × 尖峰價 + 度數 × (1 − 尖峰比例) × 離峰價`，尖峰比例拉到與帳單相符
- 電池移轉量 = 電池每日可用度數 × 每月尖峰放電天數（預設 13.5 × 22）
- 還原沒有電池時的家庭用電：
  - 家庭尖峰 = 電錶尖峰 + 移轉量
  - 家庭離峰 = 電錶離峰 − 移轉量 ÷ 0.9（離峰充電的損耗）
- 時間電價、累積電價：以還原後的家庭用電計算
- 電池容量要填「產生這張帳單時實際裝的容量」；容量填錯，還原出來的時間電價也會跟著錯
- 基本費 75 元是選時間電價才要付的實際成本，與累積電價比較時需計入；時間電價與時間＋儲能兩者都有，彼此相減時抵銷
- 儲能效益/月 = 時間電價 − 時間＋儲能（只算電池本身的效益）
- 回本年限：年省 = 夏季月省 × 4 個月 + 非夏季月省 × 8 個月，再以安裝費用除以年省

### 驗算（2026/09，夏季）

台電 App：尖峰 33.74 度、離峰 1105.48 度，時間＋儲能尖峰比例約 2.9%～3.0%，試算 NT$2,534，帳單 NT$2,528。
