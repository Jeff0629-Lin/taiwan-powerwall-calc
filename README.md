# 台灣住宅電費試算

手機 / 桌面皆可用的台灣住宅電費試算工具，比較三種方案的每月電費並估算 Powerwall 儲能回本年限。

## 功能

- **三方案比較**：累積電價 vs. 簡易型時間電價（二段式）vs. 時間電價＋儲能
- **兩個尖峰比例同時呈現**：🟢 時間電價（沒有電池時的用電習慣）、🟠 時間＋儲能（對帳單），兩者的差即為 Powerwall 移轉量；還沒裝電池的人可用電池容量一鍵估算 🟠
- **回本年限試算**：輸入 Powerwall 安裝費用，自動分季加權估算回本年數
- **即時互動**：拉桿調整用電量、兩個尖峰比例、電池容量、放電天數、夏季／非夏季
- **離線可用**：純 HTML/CSS/JS，無外部相依，存到手機即可使用

## 計算方式

- 每月總用電量：填台電 App 顯示的當月度數
- 累積電價：依級距逐段累加，**無基本費**
- 時間＋儲能：`75 + 電錶度數 × 🟠比例 × 尖峰價 + 電錶度數 × (1 − 🟠比例) × 離峰價`
- 時間電價：`75 + 家庭用電 × 🟢比例 × 尖峰價 + 家庭用電 × (1 − 🟢比例) × 離峰價`
- 累積電價：以家庭用電依級距計算
- 兩個比例之間的關係（η = 0.9 充放電效率，損耗率 k = 1/η − 1 ≈ 0.11）：
  - 移轉量 = 家庭尖峰 − 電錶尖峰
  - 損耗 = 移轉量 × k（隨每月移轉量變動，不是固定值）
  - 家庭用電 = 電錶度數 − 損耗
  - 解得：`移轉量 = (🟢 × 電錶度數 − 電錶尖峰) ÷ (1 + 🟢 × k)`
- 電池容量 × 放電天數 = 每月最多能移轉的度數，超過時顯示警告
- 「用電池容量估算」：移轉量 = min(尖峰全部移走所需量, 容量 × 天數)，反推 🟠 比例
- 基本費 75 元是選時間電價才要付的實際成本，與累積電價比較時需計入；時間電價與時間＋儲能兩者都有，彼此相減時抵銷
- 儲能效益/月 = 時間電價 − 時間＋儲能（只算電池本身的效益）
- 回本年限：年省 = 夏季月省 × 4 個月 + 非夏季月省 × 8 個月，再以安裝費用除以年省
