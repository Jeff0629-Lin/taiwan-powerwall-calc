# 台灣住宅電費試算

手機 / 桌面皆可用的台灣住宅電費試算工具，比較三種方案的每月電費並估算 Powerwall 儲能回本年限。

## 功能

- **三方案比較**：累積電價 vs. 簡易型時間電價（二段式）vs. 時間電價＋儲能
- **兩個尖峰比例**：時間電價、時間＋儲能各自一條拉桿，分別拉到與台電帳單金額相符，比例差即為 Powerwall 移走的尖峰用電
- **回本年限試算**：輸入 Powerwall 安裝費用，自動分季加權估算回本年數
- **即時互動**：拉桿調整用電量、兩個尖峰比例、夏季／非夏季
- **離線可用**：純 HTML/CSS/JS，無外部相依，存到手機即可使用

## 費率版本

採用台電 2026 年費率（經濟部 2025/10/01 調漲後）：

| 級距 | 夏季每度 | 非夏季每度 |
| --- | --- | --- |
| 120 度以下 | 1.78 | 1.78 |
| 121–330 度 | 2.55 | 2.26 |
| 331–500 度 | 3.80 | 3.13 |
| 501–700 度 | 5.14 | 4.24 |
| 701–1000 度 | 6.44 | 5.27 |
| 1001 度以上 | 8.86 | 7.03 |

時間電價（簡易型二段式）：基本電費 75 元/戶/月；尖峰 夏 5.16／非夏 4.93；離峰 夏 2.06／非夏 1.99。

## 計算方式

- 每月總用電量：填台電 App 顯示的當月度數
- 累積電價：依級距逐段累加，**無基本費**
- 時間電價、時間＋儲能：同一公式，各用各的尖峰比例
  `電費 = 75 + 度數 × 尖峰比例 × 尖峰價 + 度數 × (1 − 尖峰比例) × 離峰價`
  - 時間電價的尖峰比例：裝電池前的用電習慣（可用裝電池前的時間電價帳單對出來）
  - 時間＋儲能的尖峰比例：電錶上看到的尖峰比例（對照台電 App 或目前帳單）
- 基本費 75 元是選時間電價才要付的實際成本，與累積電價比較時需計入；時間電價與時間＋儲能兩者都有，彼此相減時抵銷
- 儲能效益/月 = 時間電價 − 時間＋儲能（只算電池本身的效益）
- 回本年限：年省 = 夏季月省 × 4 個月 + 非夏季月省 × 8 個月，再以安裝費用除以年省
